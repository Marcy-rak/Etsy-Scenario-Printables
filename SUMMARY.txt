═══════════════════════════════════════════════════════════════════
🎯 WHAT EACH WORKFLOW DOES
═══════════════════════════════════════════════════════════════════

WORKFLOW 1: Idea & Keyword Research
├─ Trigger: Schedule (daily/weekly)
├─ Action: Generate 50 product ideas with AI
├─ Output: Google Sheet populated with ideas + keywords
├─ Operations: ~10 per run
└─ Time: ~30 seconds

WORKFLOW 2: Generate Product Content
├─ Trigger: New idea in sheet (Content Generated = No)
├─ Action: 6 parallel OpenAI calls for complete content
├─ Output: Title, Description, Tags, Features, Persona, Usage Ideas
├─ Operations: ~8-10 per product
└─ Time: ~10-20 seconds (parallel execution)

WORKFLOW 3: Build Canva Products (Autofill) ⭐
├─ Trigger: Content ready (Design Created = No)
├─ Action: Canva Autofill API → Create design → Export PNG/PDF
├─ Output: High-res PNG (300 DPI), Customer PDF, Google Drive URLs
├─ Operations: ~40-60 per design
└─ Time: 2-5 minutes (async polling)

WORKFLOW 4: Create Etsy Listings (Draft)
├─ Trigger: Design ready (Listing Created = No)
├─ Action: Etsy API → Create draft → Upload image/file
├─ Output: Draft Etsy listing ready for review
├─ Operations: ~15-25 per listing
└─ Time: ~30-60 seconds

WORKFLOW 5: Create Mockups (Optional)
├─ Trigger: Listing created (Mockup Created = No)
├─ Action: Mockup service API → Generate mockup
├─ Output: Professional mockup images
├─ Operations: ~20-40 per mockup
└─ Time: ~1-3 minutes

WORKFLOW 6: Download & Organize Files
├─ Trigger: Files created (Files Organized = No)
├─ Action: Create folders → Move files → Generate metadata
├─ Output: Organized Google Drive structure
├─ Operations: ~10-15 per product
└─ Time: ~30 seconds

WORKFLOW 7: Update Existing Listings
├─ Trigger: Update marked (Update Pending = Yes)
├─ Action: Etsy API → Update listing → Log changes
├─ Output: Updated listings, change history
├─ Operations: ~8-12 per update
└─ Time: ~15-30 seconds

WORKFLOW 8: Post to Social Media
├─ Trigger: Listing created (Social Posted = No)
├─ Action: Generate caption → Post to 3+ platforms
├─ Output: Pinterest, Instagram, Facebook posts
├─ Operations: ~15-25 per post
└─ Time: ~1-2 minutes
